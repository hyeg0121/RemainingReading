코딩테스트는 프로그래머스 사이트에서 알고리즘 고득점 kit라고 문제 모아둔게 있는데 그거 풀어보면 좋을 것 같아요. (무료입니다) 저 문제 키트를 추천하는 이유는 가장 기본 알고리즘 유형들이라서…

이론 질문은 “(백엔드 or 프론트엔드) 주니어 개발자 면접질문” 이라고 구글에 검색하면 엄청 많이 나오는데 그 질문들 리스트업하고, 답 찾아보면서 준비했어요. 

그리고 저도 그렇고, 제 친구들도 손으로 코딩 시키는 경우가 좀 있어서… 엄청 간절하다면 펜으로 코드 써보는 것도 추천합니다. (단축키나 자동완성에 익숙해져서 기억 안 나는 경우가 많아요)
